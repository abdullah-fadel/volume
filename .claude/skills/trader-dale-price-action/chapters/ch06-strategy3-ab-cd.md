# Chapter 6: Strategy 3 — AB=CD

## Core Idea
Markets move in wave-like swings labeled A, B, C, D; when the C-to-D leg is measured to equal the A-to-B leg (via Fibonacci), point D becomes a market-psychology-based entry level — the author's most explicitly "psychological" (as opposed to institutional-volume-based) strategy, used mainly as confirmation.

## Frameworks Introduced
- **AB=CD pattern**: a four-point wave structure where the CD leg is set to the same pip distance as the AB leg, giving a projected reversal point D.
  - When to use: on 30-minute charts and above (the author explicitly avoids this pattern below 30-minute timeframes); as a confirming signal alongside volume-based strategies, or standalone if preferred.
  - How (author's exact steps):
    1. Mark swing point A, then swing point B (first-to-second swing distance = leg AB).
    2. Find C: a retracement of at least 50% of the AB distance, but price must not go back past A.
    3. Project D: the same pip distance from C as A is from B (so leg CD = leg AB) — this is why the pattern is named AB=CD.
    4. Bullish AB=CD → enter long at D. Bearish AB=CD → enter short at D.
  - Measurement method: place a Fibonacci tool with 0% at A and 100% at B; confirm C retraces past the 50% mark; then move the Fib tool (same measured distance) so 0% sits at C — the 100% mark now shows D, the entry point.

## Key Concepts
- **Swing points A, B, C, D**: the four labeled turning points that define the pattern; AB and CD are the two legs compared.
- **50% retracement rule for C**: C must retrace at least half of the AB distance without exceeding point A — this is the pattern's validity filter.
- **Fibonacci tool (as a measuring device, not a signal)**: used purely to transfer the AB distance onto the CD leg to project D, not for its traditional retracement-level signals.

## Mental Models
- Think of AB=CD as reading market psychology/rhythm (repeating wave amplitude) rather than institutional footprints — the author separates it conceptually from his volume-based core method.
- Use it as one more confirmation layer: "the more confirmations, the better" is the author's stated philosophy for combining Price Action strategies with his main volume-based approach.

## Anti-patterns
- **Applying it below 30-minute timeframes**: the author explicitly states he doesn't look for this pattern on timeframes below 30 minutes.
- **Letting C retrace past A**: invalidates the pattern — C must stay within the AB range (retrace ≥50% but not exceed A).
- **Treating it as a standalone primary strategy for every trade**: while it works standalone, the author's default use is as a secondary confirmation for his institutional/volume-based setups.

## Worked Example
Bullish AB=CD, EUR/USD 60-minute chart: swing low A to swing high B is measured, C retraces more than 50% of the AB leg without breaching A, and the Fibonacci tool is shifted (0% at C, same AB distance preserved) to project D — price reaches the projected D level and a long is entered there. A bearish mirror-image example is shown on EUR/USD 240-minute (4-hour) chart: A-to-B down leg, C retraces upward past the 50% mark without exceeding A, and D is projected below C by the same distance as AB — a short is entered at D.

## Key Takeaways
1. Validate C's retracement (≥50% of AB, not past A) before projecting D — this is the pattern's core filter.
2. Use the Fibonacci tool mechanically: 0%→A/100%→B first to validate C, then 0%→C to project D.
3. Restrict this pattern to 30-minute charts and above.
4. Treat AB=CD primarily as a confirmation layer for volume-based entries, not a standalone primary system.
